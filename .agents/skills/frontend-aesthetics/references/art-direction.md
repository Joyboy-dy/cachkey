# Art direction prompts

When composition is unclear, answer these before styling:

- What must the user notice first, second, and third?
- Which content is primary, supporting, or metadata?
- Which actions are primary vs secondary/destructive?
- Does the screen need calm density, information density, or promotional emphasis?
- Which existing product surfaces should this screen visually belong to?
- What should remain visually quiet?

A direction should be expressible in a few constraints, not a long list of effects. Example: “dense operational interface; neutral surfaces; strong type hierarchy; thin separators; one accent for actions; motion only for state transitions.”
