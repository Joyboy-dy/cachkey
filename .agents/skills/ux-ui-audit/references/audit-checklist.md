# Audit completion checklist

- Scope and evidence sources are stated.
- Findings include exact location/evidence.
- Severity is tied to user impact.
- Keyboard/focus behavior was checked where interactive access existed.
- Form error/label behavior was checked where forms exist.
- Loading/empty/error states were sampled.
- Responsive reflow/overflow was sampled.
- Theme/color contrast claims were actually measured when numeric claims are made.
- Automated findings were manually interpreted.
- Recommendations preserve existing system conventions unless a redesign is requested.
- Unverified items are labeled as such.
