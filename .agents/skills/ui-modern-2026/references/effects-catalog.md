# Effects catalog

Effects should communicate hierarchy/state or establish a deliberate art direction.

Prefer: subtle elevation, purposeful blur only behind readable surfaces, restrained gradients, transitions tied to state changes, reduced-motion variants, and performant transform/opacity animation.

Avoid: glow on every control, multiple translucent layers that obscure contrast, continuous decorative motion, expensive filter stacks on large scrolling surfaces, and effects that mask weak hierarchy.
